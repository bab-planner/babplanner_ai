# 실험 기록

**아직 비어 있다.** W1에서 학습을 하지 않았다.

여기에는 실험마다 하위 디렉터리를 만들고, 그 안에 **작은 기록 파일만** 둔다.

```
experiments/
└─ <stage>_<name>/
   ├─ freeze.json          결과를 보기 전에 동결한 설정과 판정 규칙
   ├─ development.json     후보 비교 결과
   ├─ final.json           한 번만 채점한 결과
   └─ metrics.csv          표로 옮긴 값
```

`.gitignore`가 이미지·가중치·큰 산출물을 막는다. `.json` / `.yaml` / `.csv`만
남는다. CCTV 트랙(`research/cctv_counting/experiments/`)과 같은 규칙이다.

## 규칙

**결과를 보기 전에 동결한다.** 후보 목록, 선택 규칙, guardrail, 분할을 먼저
정하고 지문(SHA-256)을 남긴다. 그 다음에 돌린다. CCTV A4~A6에서 이 절차가
결론을 두 번 뒤집었고, 그때마다 뒤집힌 쪽이 옳았다.

**평가 집합은 한 번만 본다.** 한 번 결과를 본 집합은 그때부터 분석용이다.
그 집합에서 다시 고르지 않는다.

**데이터가 적으면 한 번의 분할로 결론을 내지 않는다.** 그룹 단위
cross-validation의 폴드별 값과 그 분산까지 함께 적는다.
