### 표본 하나를 처리하는 순서

```
[ ] 배식받은 식판을 통째로 저울에 (식기 포함)
[ ] 숫자 적기
[ ] 식사
[ ] 사진 — 식판 전체 / 위에서 / 그림자 없이
[ ] 화면에 얼굴·학생증·명찰·문서·다른 사람 없음
[ ] 남은 식판을 통째로 저울에
[ ] 숫자 적기
[ ] add-sample 실행
[ ] 화면에 나온 잔반률이 눈으로 본 식판과 비슷한지 확인
```

사진이 흔들렸거나 식판이 안 보이면 → `--label REJECTED --rejection-reason ...`

---

## 오류가 났을 때

```
[ ] "식기 무게보다 크지 않습니다"   → tare 프로파일 / 저울 다시 확인
[ ] "식기 무게보다 작습니다"        → 다른 식기를 썼는지 확인
[ ] "잔반량이 제공량보다 많습니다"  → 두 숫자가 뒤바뀌었는지 확인
[ ] "같은 이미지가 이미 있습니다"   → 사진을 두 번 넣었는지 확인
```

**숫자를 고쳐서 통과시키지 않는다.** 무엇이 잘못됐는지 찾는다.

이미 등록한 뒤에 잘못을 알았으면 → `correct-sample`
